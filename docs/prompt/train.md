## 2. TRAINING OBJECTIVE

The objective is to train a model that predicts 21 3D hand keypoints (x, y, z coordinates) directly from radar data. 

**Data Flow**: Radar tensor -> Radar Encoder -> Pose Regressor -> 21x3 (63-dimensional) coordinate prediction.

Ground-truth supervision comes ONLY from the 3D JSON annotations generated by the Depth-Anything pipeline. During inference, ONLY radar input is available. Camera images are NEVER used during inference.

## 3. DATASET IMPLEMENTATION (`core/dataloader.py`)

Each sample consists of:
- **Radar**: `/work/tuan.tt19010226/HPE-3D/dataset/raw_ds/matched_radar/`
- **3D Hand JSON**: `/work/tuan.tt19010226/HPE-3D/dataset/raw_ds/matched_camera_hand_json_3d/`

**Requirements**:
- Recursively discover all radar `.npy` files and automatically locate corresponding `.json` files.
- Verify synchronization, detect missing files, and skip corrupted samples.
- Support train/validation/test split, multi-worker DataLoader, and cache metadata.
- Handle samples where `hand_or_no_hand` is "no hand".
- **Return format**: `{ radar_tensor, keypoints_3d, hand_status, handedness, sample_id }`

## 4. ARCHITECTURE IMPLEMENTATION (`core/network.py`)

**IMPORTANT**: A pre-built neural network architecture (`DevModel7`) is already provided in `/work/tuan.tt19010226/HPE-3D/core/network.py`. You MUST use this existing network for training. Do not implement a new Radar Encoder or Pose Regressor from scratch.

### 4.1 Radar Preprocessing
Handle the raw radar representation `(8, 64, 64)`. The network expects an input with `in_channels=8`. Ensure your dataloader or preprocessing pipeline feeds the tensor directly to the network in the expected shape `(batch, 8, 64, 64)`.

## 5. TRAINING PIPELINE (`scripts/train.py`)

- **Targets**: Regress the 21 3D keypoints (x, y, z) for samples where a hand is present. Optional: Multi-task loss (predicting hand presence/handedness alongside pose).
- **Loss**: L1 Loss or Mean Squared Error (MSE) for keypoint regression. CrossEntropy for hand presence classification (if used).
- **Support**: PyTorch (or PyTorch Lightning). Include DataLoader, optimizer, scheduler, mixed precision, checkpoint saving, resume training, TensorBoard logging.
- **Workflow**: Save checkpoints periodically, compute validation loss.

## 6. EVALUATION & INFERENCE

### 6.1 Evaluation (`scripts/val.py`)
Metrics to implement:
- **MPJPE** (Mean Per Joint Position Error) in 3D space.
- **PCK** (Percentage of Correct Keypoints) at various thresholds (e.g., PCK@0.05, PCK@0.1).

### 6.2 Inference (`scripts/infer.py`)
- **Input**: Radar only. 
- **Output**: 21 3D keypoints.
